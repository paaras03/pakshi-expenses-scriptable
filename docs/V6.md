# Scriptable V6

V6 is the Scriptable-only Pakshi Expenses prototype.

## Changes from V5

- Keeps the tested 95px top safe area.
- Preserves the V3 interaction model.
- Adds Google Sheets persistence through Apps Script.
- Adds expense create/edit/delete.
- Adds income detail/edit.
- Adds savings detail/edit.
- Adds category detail.
- Adds expense sorting.
- Adds CSV export.
- Keeps four primary tabs: Home, Add, Budget, Settings.
- No Supabase connection.
- Uses GET transport for writes because POST response handling through Apps Script was slow/unreliable in Scriptable testing.

## Run

Open `pakshi-v6.js` in Scriptable and run it.

On first run it asks for:

1. Google Apps Script Web App URL
2. no API token

Both values are stored in Scriptable Keychain.

## Known prototype limitations

- Writes currently take several seconds because the prototype goes through Google Apps Script and refreshes data after mutations.
- The prototype uses a public/editable Google Sheet and unauthenticated Apps Script endpoint. It is not appropriate for sensitive or production financial data.
- The native production implementation remains Supabase Auth + RLS. The prototype is expected to migrate to that backend architecture later.
