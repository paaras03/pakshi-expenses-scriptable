# Scriptable V6

V6 is the Scriptable-only Pakshi Expenses prototype.

## Changes from V5

- Keeps the tested 95px top safe area.
- Preserves the V3 interaction model.
- Adds Google Sheets persistence through Apps Script.
- Adds expense create/edit/delete.
- Adds income detail/edit.
- Adds savings detail/edit.
- Adds category detail.
- Adds expense sorting.
- Adds CSV export.
- Keeps four primary tabs: Home, Add, Budget, Settings.
- No Supabase connection.

## Run

Open `pakshi-v6.js` in Scriptable and run it.

On first run it asks for:

1. Google Apps Script Web App URL
2. no API token

Both values are stored in Scriptable Keychain.

## Known prototype limitation

The Google Apps Script token is bearer authentication. This is acceptable for this controlled prototype but is not equivalent to Supabase Auth + RLS.
